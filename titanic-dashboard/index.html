분석 한계 및 개선 방향

해석상의 한계: Titanic 자료는 891명으로 규모가 작으며, Cabin 누락 비율이 높고 사회·역사적 배경의 교란 요인이 포함될 수 있습니다. 관찰된 생존율 차이는 인과관계를 입증하지 않습니다.

모델상의 한계: 단일 홀드아웃 분할 및 소규모 외부 CV 기반 결과에는 불확실성이 있습니다. 변수 중요도는 테스트 데이터에서 설명 목적으로 계산한 것으로 모델 재선정에는 사용하지 않았습니다.

개선 제안: 반복 중첩 교차검증, 확률 보정, 임계값 민감도 분석, 결측치 대체 전략 비교, 타이틀 파생변수의 일반화 검증이 적절합니다. 새로운 외부 데이터에 적용한다면 분포 차이 확인이 우선입니다.

전처리 변수: Age, FareLog, SibSp, Parch, FamilySize, IsAlone, Sex, Pclass, Embarked, Title, HasCabin. PassengerId / Name / Ticket / Cabin 원문은 직접 예측 변수로 사용하지 않고, Name의 Title과 Cabin의 유무만 파생변수로 반영했습니다.
